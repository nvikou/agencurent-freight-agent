## 2. Преимущества Dellin

- Dellin дешевле конкурентов на **1** маршруте(ах) из 6.
- Сроки Dellin на ряде направлений (СПб ↔ Москва, СПб ↔ Омск) конкурентны.

## 3. Недостатки Dellin

- Dellin дороже минимум на одном конкуренте на **5** маршруте(ах) из 6.
- На направлении Омск → Москва цена Dellin существенно выше ПЭК и Baikal.

## 4. Рекомендации

- Для клиентов, чувствительных к цене, явно сравнивать транспорт базы без опций (как в этом отчёте).
- Углубить анализ на Омск → Москва: проверить позиционирование тарифа Стандарт.
- Периодически обновлять quotes (`collect_quotes.py`) и смотреть `collected_at`.
